How to use SDX Inspect

Admin: set up a venue

You set up a new venue in seven steps: invite the team, make the stand list, print the stand posters and the equipment stickers, walk every stand, verify it, and connect the people at each stand. Practice on the demo with badge 448800. It is an inspector account, so it can do every step except the invites and the venue name and logo, which need a venue admin. Other visitors share the demo, so undo what you add.

Try it on the live demo

The demo is a made-up venue. Other visitors use it too.

Step by step

  1. Open the setup checklist

    • Open the demo and sign in with badge 448800.
    • Open the ☰ menu → Set up this venue (N of 7).
    • Do the 7 steps in order. Each one shows how far you are.
    • Tap Go to open its screen (a step that is already done shows Open).
    • Nothing is mandatory. You can come back any time.
    Set up this venueGoOpen

    On a new venue with no stands yet, this page opens by itself after you sign in.

    Try it in the demo Sign in with badge 448800, then open the ☰ menu.

  2. Add your venue name and logo

    • Open the ☰ menu → Admin Panel → the Venue name & logo card.
    • Type the venue name. Add a company name if you want it in the header.
    • Tap Pick a picture for the logo, then tap Save.
    • The name goes on every stand poster and equipment sticker.
    Admin PanelVenue namePick a pictureSave

    Do this before you print, so posters and stickers carry your name.

    Try it in the demo Badge 448800 is an inspector, so it does not see the Admin Panel. A venue admin account does this step.

  3. Invite your team

    • Admin Panel → 🔗 Invite links. Tap Create link for each role.
    • Tap 📱 Text or QR to send the link.
    • Cleaning, Maintenance and Ecolab crews only type their name — no badge. Inspectors and managers pick a badge number.
    • ↻ New makes a new link. The old link stops working, and crew phones that joined with it are signed out. People with a badge keep signing in with their badge.
    🔗 Invite linksCreate link📱 TextQR↻ New

    A crew phone stays signed in after it opens the link — no idle lock.

    Try it in the demo See what a cleaning crew member gets from your link: type a name and the board opens, no badge.

  4. Import the stand list

    • Setup step 2 Make the stand list → Go (or Open).
    • Tap ⬇ Template and fill in Unit, Name, Floor, Type and License, and delete the sample rows. Bars and pantries: leave License empty.
    • Tap 📥 Import stands from Excel / CSV and pick your file.
    • Check the list: pick a type where it says TYPE?, tap ✓ right on each amber type that is correct (a guess you do not confirm is added with no type), then tap ＋ Add N stands.
    Make the stand list⬇ Template📥 Import stands from Excel / CSVTYPE?✓ right↩ Undo this import

    Made a mistake? ↩ Undo this import takes those stands off the list again.

    Try it in the demo Other visitors share the demo — after a test import, tap ↩ Undo this import.

  5. Add a stand by hand

    • In ➕ Add a stand, pick the type first.
    • Type the Unit #, the name and the floor.
    • Add the license number. A Bar or a Pantry needs none.
    • Tap ＋ Add stand.
    ➕ Add a standUnit #Floor＋ Add stand

    Removed a stand by mistake? Tap ↩ Undo right away.

    Try it in the demo Add one test stand, then remove it with ✕ — other visitors share the demo.

  6. Print the stand posters

    • Setup step 3 Print the stand posters → Go (or Open).
    • Tap a floor button to pick that floor, or Select All.
    • Tap 🖨 Print. You get one poster per stand, in floor and unit order.
    • Tape each poster where that stand's team sees it.
    Print the stand postersSelect All🖨 Print

    Print one floor at a time. A big print job gets a divider page at the start of each floor.

    Try it in the demo This is what a stand's poster opens: the stand's temperature log, no app.

  7. Print equipment stickers

    • Setup step 4 Print equipment stickers → Go (or Open), or tap 🏷 Stickers on the Equipment & stickers tab.
    • Pick Every stand or one floor for the units already on file.
    • For units not in the system yet, print blank stickers — about 5 per stand.
    • Use Avery 5163 / 8163 (2" × 4", 10 per sheet) and print at 100% / Actual size.
    Print equipment stickers🏷 StickersEvery standBlank stickers for units not in the system yetSkip the first labels on the sheet

    Used part of a sheet already? Set Skip the first labels on the sheet.

    Try it in the demo The demo already has coolers and freezers on file — pick one stand and print a test sheet.

  8. Walk-through: a sticker on every unit

    • At the stand, tap 📷 Scan a poster or sticker and scan the stand's poster.
    • Put a sticker on each unit, tap 📷 Scan stickers and scan it.
    • Tap what it is and type the Serial number from the nameplate.
    • Tap ✅ Sticker on — done.
    📷 Scan a poster or sticker📷 Scan stickersWhat is it?Serial number✅ Sticker on — done

    Serial already on file at another stand? Tap ↔ Yes — move it here: the unit keeps its history.

    Try it in the demo No sticker at hand? Open BURGER BASE #101, tap 📷 Scan stickers and type SDX-CL-101-1 in the box under the camera.

  9. Verify each stand

    • Tap 🔍 Verify walk and open a stand.
    • For each unit tap ✔ It's here, ✏ Fix or 🗑 Not here — or just scan its sticker.
    • When every unit is confirmed, tap ✅ Mark stand verified.
    🔍 Verify walk✔ It's here✏ Fix🗑 Not here✅ Mark stand verified

    A stand with no cold equipment? Tap ✅ Verified — no cold equipment here.

    Try it in the demo Open a demo stand with a cooler, such as TACO TERRACE #104, and confirm its unit.

  10. Connect the stand people

    • On a stand's poster card, tap ＋ Add person.
    • Type the name and phone, then tap ✓ Save.
    • Tap ✉ Text link: the supervisor gets their own link to that stand, with their name already in.
    • To go through everyone, open 👥 People → 📨 Text everyone (one text per person).
    ＋ Add person✓ Save✉ Text link👥 People📨 Text everyone

    People who already logged from a stand's poster show up on its card by themselves.

    Try it in the demo Demo phone numbers are made up — read the text, but do not send it.

Quick check

Three questions. Get 2 of 3 right to finish this guide.

1. Which stands need no license number?

The app treats a Bar and a Pantry as license-exempt. Leave the License box empty for them.

2. How do you print the equipment stickers so they land on the labels?

The app says to print at 100% / Actual size, not "Fit to page", on a 2" × 4" sheet of 10 — best from a computer.

3. Why do you type the serial number on the walk-through?

The sticker's QR is only the tag. The serial is the unit's identity, so a moved unit is found again (↔ Yes — move it here).

Answers
  1. 1. Bars and pantries — The app treats a Bar and a Pantry as license-exempt. Leave the License box empty for them.
  2. 2. At 100% / Actual size, on Avery 5163 or 8163 — The app says to print at 100% / Actual size, not "Fit to page", on a 2" × 4" sheet of 10 — best from a computer.
  3. 3. It keeps track of the unit if it moves to another stand — The sticker's QR is only the tag. The serial is the unit's identity, so a moved unit is found again (↔ Yes — move it here).
