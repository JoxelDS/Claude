# @sdxinspect — set up the account (about 5 minutes, on your phone)

1. **Create the account.** Instagram → your profile → tap your username at the top → **Add account** → **Create new account**. Username: `sdxinspect`.
2. **Profile picture:** `profile.png` (this folder).
3. **Name:** `SDX Inspect · Inspection App`. Putting "Inspection App" in the name field makes the account show up when people search those words.
4. **Bio** (paste as is):
   ```
   The inspection app for food stands & kitchens 🌡️
   Temps · problems · crews · proof — in one app 📲
   🇪🇸 Inspecciones sin papel
   Built by @dsmarketing.agency
   ```
5. **Make it Professional:** Settings → **Account type and tools** → **Switch to professional account** → **Business** → category **Software** (or "App Page").
6. **Link a Facebook Page.** This is required so the automation can post Reels. In the Instagram app go to Edit profile → **Page** → **Create a new Facebook Page** called "SDX Inspect". Use the SAME Facebook login that is connected in Make (Joxel Dasilva).
7. **Give Make access to it:** Make → Connections → the Facebook / Instagram connection → **Reauthorize** → tick the new **SDX Inspect** Page and the **@sdxinspect** Instagram account → Save.
8. Tell Claude **"sdxinspect is ready"**. Claude then finds the account in Make, creates the posting scenario, posts the first Reel (temps) and starts posting every daily Reel on both accounts.
