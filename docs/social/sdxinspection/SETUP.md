# @sdxinspection — set up the account (about 5 minutes, on your phone)

1. **Create the account.** Done 2026-10-10 — `@sdxinspection`, name "SDX Inspection system".
2. **Profile picture:** `profile.png` (this folder).
3. **Name:** `SDX Inspect · Inspection App`. Putting "Inspection App" in the name field makes the account show up when people search those words.
4. **Bio** (paste as is):
   ```
   The inspection app for food stands & kitchens 🌡️
   Temps · problems · crews · proof — in one app 📲
   🇪🇸 Inspecciones sin papel
   DM "PILOT" for a free 30-day pilot
   ```
   **Bio link:** `https://joxelds.github.io/Claude/marketing/` (the product page; its first button opens the live demo). Do not use a `cloudfront.net` link — those video links expire.
5. **Make it Professional:** Settings → **Account type and tools** → **Switch to professional account** → **Business** → category **Software** (or "App Page").
6. **Link a Facebook Page.** This is required so the automation can post Reels. In the Instagram app go to Edit profile → **Page** → **Create a new Facebook Page** called "SDX Inspect". Use the SAME Facebook login that is connected in Make (Joxel Dasilva).
7. **Give Make access to it:** Make → Connections → the Facebook / Instagram connection → **Reauthorize** → tick the new **SDX Inspect** Page and the **@sdxinspection** Instagram account → Save.
8. Tell Claude **"sdxinspection is ready"**. Claude then finds the account in Make, creates the posting scenarios (photo, carousel, Reel) and the SDX Post Queue starts posting once a day (https://claude.ai/artifact/Bd3w9RC1T2wwfujnCqY4CR).

## Story highlights

- `highlight-crews.png` → Crews
- `highlight-stands.png` → Stands
- `highlight-howto.png` → How to

## Two accounts, two jobs
- **@sdxinspection**: the product. The app's own look (navy, white, red), product captions, "DM us PILOT" + the live demo link.
- **@dsmarketing.agency**: your agency's own account (its own look and captions). Nothing on @sdxinspection, in the app or in the SDX sales material mentions DS Marketing.

SDX Reels post on @sdxinspection from the SDX Post Queue. A Reel goes on @dsmarketing.agency only when Joxel says so.
